# Sankey - VisuallyJs React

A Sankey diagram is a type of flow diagram in which the width of the arrows is proportional to the flow rate. They are widely used to visualize the transfer of energy, money, or materials between different processes, making it easy to identify the most significant contributors to a flow and where losses might be occurring.

VisuallyJs offers a professional Sankey chart which has support for pivoting the view.

https://visuallyjs.com/demonstrations/sankey
